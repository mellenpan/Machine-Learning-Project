As the environment and climate changes in the US, the question becomes, are we able to predict the patterns of air quality changes based on the past? Using a U.S. Pollution Data dataset containing historical measurements of major pollutants across locations in the United States, we will investigate whether a machine learning model trained on one city can generalize to cities with different climates. We will perform exploratory data analysis (EDA) to identify trends in pollution levels across five selected cities. To predict pollution levels, we will use supervised learning techniques, including:

•	Linear Regression, which will provide an interpretable baseline for predicting pollution levels.

•	Random Forest and Gradient Boosting, which will allow us to capture more complex and non-linear relationships in the data.

By comparing the performance of Linear Regression with more complex ensemble methods using mean absolute error (MAE) and root mean squared Error (RMSE), we will be able to evaluate our models and determine how accurately they generalize across different cities and climates. The combination of techniques helps select the best machine learning approach that is the most reliable when predicting pollution across different geographic regions.
